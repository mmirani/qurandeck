# QuranDeck

A personal mushaf for The Noble Quran: search by word, theme, surah, or verse key; bookmarks and notes; recitation that can start from a word, a verse, or your current place; traditional and modern colour themes.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3310](http://localhost:3310). Port 3310 is used locally so it does not collide with other apps on 3000.

## Sources

- [Quran.com API v4](https://api.quran.com/api/v4) — chapters, verses, word-by-word, recitations, translations, juz, search
- [AlQuran Cloud](https://alquran.cloud/api) — extra translation editions and text search
- [audio.qurancdn.com](https://audio.qurancdn.com) — word and ayah recitation
- [Islamic Network CDN](https://cdn.islamic.network) — ayah audio fallback

Bookmarks, notes, and local accounts stay in the browser for this first slice.
